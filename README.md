# Consultório+ — Clinic Management Web App

[PREVIEW](https://orizon-teal.vercel.app/)

A front-end prototype for a clinic management system, focused on appointment
scheduling, patients, payments, and the clinic's daily workflow.

## Features

- Dashboard with daily appointments, attended patients, revenue, and reminders
- Appointment scheduling by doctor and date
- Create, edit, cancel, and transfer appointments
- Patient registration
- Doctor availability and blocked periods
- Payment method and payment status management
- Appointment search and filters
- Form validation and input masks
- Responsive layout

## Tech Stack

- React
- TypeScript
- Bootstrap 5
- Bootstrap Icons
- CSS
- Create React App

Bootstrap is used mainly for the grid, responsive utilities, forms, buttons,
and spacing. Custom CSS is used for the visual identity and specific
components.

## My Process

I used my own notes, previous projects, and code I had written before as a
starting point for the implementation.

For UI inspiration, I looked at dashboard designs such as:

- [Logip — Admin Dashboard Analytics UX](https://dribbble.com/shots/21590789-Logip-Admin-Dashboard-Analytics-UX)
- [Sequence — Financial Dashboard](https://dribbble.com/shots/23683691-Sequence-Financial-Dashboard)

I also used [Coolors](https://coolors.co/palettes/trending) to explore color
palettes and the [Bootstrap documentation](https://getbootstrap.com/docs/5.3/)
as a reference for the layout and components.

I used AI to help generate the mock data used in the application, such as
patients, doctors, appointments, and reminders.

I also used GitHub Copilot in VS Code only for autocomplete and TypeScript type
suggestions. The architecture, component organization, and design decisions
were made by me.
